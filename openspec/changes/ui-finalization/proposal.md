## Why we're doing this

### Qualified Problem
**For:** Primary school children (grades 3–5)
**Who:** Need an intuitive, engaging, and guided interface to learn word problems
**The:** Current React app navigation and dashboards
**That:** Act as a clean dashboard, but lack a strong visual sense of progression (such as a Duolingo-style learning path), friendly step-by-step introduction screens, and direct error-review list interfaces.
**Unlike:** The high-fidelity mobile prototype (`tonymath-mobile-prototype.html`) which excels at gamification, visual path mapping, and clear preparatory lesson flows.
**Our approach:** Port the visual gamification components (Duolingo-style zigzag learning path, Mascot Lesson Intro screen, Daily Quests list, and dedicated incorrect questions list) from the HTML prototype into the React app's modular views.

## What's changing

We analyzed the current React screens against the prototype and identified four major gaps:
1. **Vertical Gamified Learning Path**: The React `LessonsMenu` currently uses simple accordion lists. The prototype uses a vertical zigzag path (`.path`) with Done, Active, Locked, Chest, and Boss nodes.
2. **Mascot Lesson Intro Screen**: The React app jumps directly into the exercise steps. The prototype has an introductory mascot speech screen outlining facts (Knowns & Unknowns) and exercise steps to prime the student's mind.
3. **Daily Quests with Calendar**: The prototype includes a daily tasks banner and a weekly calendar tracking study streak, motivating kids to maintain consistency.
4. **Incorrect Questions Review**: The prototype has a dedicated screen displaying mistakes grouped by step tags (Mô hình, Phép tính, Đáp án) with direct retry triggers.

### Options Evaluated

#### Option A: Gamification and Path Engine (Duolingo Map + Quests Calendar)
* **Approach:** Replace the chapter accordion in `LessonsMenu` (or enhance the `Home` dashboard) with a Duolingo-style zigzag learning path mapped to lessons. Add the daily quests section and weekly calendar.
* **Philosophy:** Balanced / Gamification-first
* **Effort:** Medium (~3 days)
* **Risk level:** Low
* **Pros:** Highly engaging, visually impressive, clear progress representation.
* **Cons:** Does not address prep-flow (intro) or mistake tracking.

#### Option B: Pedagogical Flow (Mascot Intro Screen + Dedicated Error Review List)
* **Approach:** Focus strictly on learning preparation and post-lesson analysis. Build the Mascot Lesson Intro screen displaying facts (known/ask) before exercises begin. Create a dedicated "Ôn câu sai" panel with grouped errors.
* **Philosophy:** Educational / Pedagogical-first
* **Effort:** Medium (~2 days)
* **Risk level:** Low
* **Pros:** Enhances problem-solving structure, reinforces learning by forcing correction of past errors.
* **Cons:** Keeps the current boxy card layout on the Home page and Lessons map, which looks less premium.

#### Option C: Unified Premium Redesign (Hybrid)
* **Approach:** Port the full set of key prototype features:
  1. Add the **Duolingo-style zigzag path** under a new layout option in `LessonsMenu` or at the bottom of the `Home` page.
  2. Implement the **Lesson Prep Intro view** right before entering `LessonView`.
  3. Add the **Daily Quests checklist & week calendar** widget to the Home dashboard.
  4. Build the dedicated **"Ôn câu sai" review list** under `InsightsView`/Profile.
* **Philosophy:** Balanced / Premium-redesign
* **Effort:** Large (~5 days)
* **Risk level:** Medium (requires code changes across multiple views in `src/App.jsx`)
* **Pros:** Delivers a complete, premium, high-fidelity experience that matches the prototype's goals.
* **Cons:** Higher implementation effort.

---

### 🎯 Recommendation

**Choose Option C: Unified Premium Redesign (Hybrid)**

#### Why Option C:
1. **Kid-focused Gamification:** Children in grades 3-5 respond strongly to visual paths (zigzag lines, chests, boss locks) and daily checklist rewards.
2. **Pedagogical Prep:** Standardizing the transition screen (Intro facts) prepares the student's mind and reduces anxiety before beginning interactive math questions.
3. **Structured Review:** Easy tracking of mistakes with clear tag labels matches the gamified review features of Duolingo (e.g. Mistakes Inbox).
